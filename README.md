GOLDFRAME STUDIO — POSTER-ONLY WEBSITE
======================================

Website file: index.html
The website is mobile-friendly and includes:
- GoldFrame Studio branding
- Poster-only portfolio mockups
- Starter prices: ₱100, ₱150, ₱250
- Messenger order button
- Simple order steps

BEFORE PUBLISHING
1. Create a Facebook Page for GoldFrame Studio (if you do not already have one).
2. Get the Page username or Messenger link.
3. Open index.html in a text editor.
4. Search for YOUR_PAGE_USERNAME and replace it with your actual Page username.
   Example link format: https://m.me/yourpageusername
   If you have a different working Messenger link, replace the href URL with it.
5. Save the file and test the button.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Go to https://github.com/ and sign in.
2. Create a PUBLIC repository named goldframe-studio.
3. Upload index.html to the top level of the repository.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and / (root), then Save.
7. Wait for the website link to appear on the Pages settings screen.
8. Open the link on your phone and test the Messenger button.

NOTES
- GitHub Pages can host a static website free from a public repository.
- The site does not store orders or customer details; customers contact you through Messenger.
- The portfolio art is made from HTML/CSS mockups to show concepts. Do not describe them as client work.
- Prices are starter examples; change them in index.html if needed.
- Do not place private data in a public repository.
